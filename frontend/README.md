# SkyBook AI Frontend

React SPA for the SkyBook AI **security training lab**.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite dev server on :3000 |
| `npm run build` | Production build |
| `npm test` | Vitest + RTL |

## Env

See `.env.example`:

- `VITE_API_URL` (default `/api/v1`)
- `VITE_AI_URL` (default `/ai/api/v1`)
